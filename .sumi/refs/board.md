## Category norm (meet it)
- One accent colour, spent sparingly
- Small, quiet UI type against large display type
- Smooth scroll (Lenis on 2 of 3)
- Round / pill menu controls

## Direction
Type: display Inter 600, clamp(52px, 8.6vw, 124px), tracking -0.05em, leading 0.94; body Inter 400 17px / 1.6; contrast ratio 7.3
Color: page #FFFFFF, ink #021F53, muted #5A6478, accent #FD9F0F (hero only), blocking: one navy band (Why Crisp) + butter #FFF4E8 tint sections
Rhythm: section padding 152 / 80, grid 12, container 1240
Shape: radius 999px controls, 20px cards, 32px feature cards, 12px small
Motion: smooth scroll (Lenis, duration 1.1), house easing cubic-bezier(.22,1.2,.36,1), tempo .3s UI / .8s reveal; signature: Remotion "assemble → crunch" hero (Santioni trait), applied once on load
Hero: CTA "Let's chat" stays the only button; CoMinVi gateway tiles (Work ▸, Services ▸) replace the text link
Work page: Gil Huybrecht frame strips — client name left, frames numbered 01–0N, tags + one line under

## Avoid
- Dark full-bleed pages (brand rule: background always white or light)
- A second typeface (category leans Helvetica + mono; brand is Inter only)
- WebGL scenes that slow the first screen

## Rejected (and why)
- Black textured backgrounds from Santioni: brand forbids dark theme
- Age gate + ambient audio from Santioni: friction before the one action
- Cinematic dark video hero from CoMinVi: competes with the croissant and the CTA
- Helvetica + PP Supply Mono pairing from CoMinVi: brand is one family (Inter)
- Barba page transitions from CoMinVi: adds weight for a 6-page static site
- Black WebGL infinite gallery from Gil Huybrecht: second trait from the same site + dark
